# OpenCircuit
An open-source arcade racing game for the PyBadge, featuring custom community-made tracks, online leaderboards, optional ESP32-powered WiFi, and a lightweight engine built for retro handheld hardware. Designed to be moddable, hackable, and built together.
# Hardware
OpenCircuit was created to run on the Adafruit Pybadge (with an ESP32 feather attached via header pins).
